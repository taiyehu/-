# 联机 Demo

在项目根目录运行：

```powershell
cd demo
node server.js
```

打开 `http://localhost:3000`。裁判创建房间，三个队伍各用独立浏览器或设备输入房间码，分别选择 A、B、C 队。其他设备访问时使用运行服务器的电脑局域网地址，例如 `http://192.168.1.10:3000`。运行 `node --test` 可检查核心规则。

本版使用每队独立的十张移动牌（步数为 `1,1,2,2,3,3,4,4,5,6`），每队初始六张手牌，起点暂定 A=`R1`、B=`R5`、C=`R9`。选牌后，地图会高亮所有可到达终点；点击终点会提交移动，队伍图标依次经过路线上的节点。经过房屋时可以提前停留。这些参数在 `game.js` 顶部可修改。房间数据暂存在服务器内存；重启服务器会清空房间。

地图对所有队伍完整显示；战斗表按队伍的当前轮次和记录到达时间过滤，裁判显示全量。Arcaea 支线按地图箭头为 `R12 → A2 → Arcaea → A1 → R1`。移动只结算路径和占领登记；收入、收税、事件、厄运、房屋效果尚未进入本版。裁判可手动调分，同轮同格战斗可手动选择胜者。厄运 B 的双向通路是当前 demo 的临时设定，正式玩法需要确认方向。刷新页面会恢复本机当前席位；每个浏览器配置文件只能保持一个席位。
